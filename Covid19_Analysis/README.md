# Data Analysis Portfolio Projects

## Covid-19 Data Exploration

### Overview
Exploratory data analysis on global Covid-19 deaths and vaccinations dataset using MySQL and Tableau.

### Skills Used
SQL (Joins, CTEs, Temp Tables, Window Functions, Aggregate Functions, Creating Views), Data Visualization (Tableau)

### Key Insights
- Global death rate from Covid-19 was approximately 2.12%
- Europe had the highest total death count by continent at over 1 million deaths
- Andorra had the highest infection rate relative to population at approximately 17%
- Africa had significantly lower recorded deaths compared to other continents, likely reflecting reporting limitations
